# Развёртывание на сервере (веб-версия для команды)

Эта инструкция — для размещения калькулятора на настоящем сервере в интернете, чтобы
менеджер, цех и владелец заходили с разных компьютеров по одной ссылке, под своими
аккаунтами.

## Что нужно перед началом

1. **Сервер (VPS)** с Linux и установленным Docker. Взять можно у любого хостинг-провайдера,
   принимающего российские карты — например, Timeweb Cloud, Selectel, VK Cloud. Минимальной
   конфигурации (1-2 ГБ RAM) достаточно. Стоимость обычно от ~300-500 ₽/мес.
   При заказе выбирайте образ **"Docker"** или **Ubuntu 22.04/24.04** (Docker установим сами).
2. Доступ к серверу по SSH (провайдер выдаёт IP-адрес, логин `root` и пароль или ключ
   сразу после оплаты — обычно приходит на почту или показывается в панели управления).

Я не могу арендовать и оплатить сервер за вас — это шаг с вашей картой. Как только он будет
готов (у вас будет IP-адрес и доступ по SSH), пришлите мне — и я проведу через настройку
пошагово, как и с локальным запуском.

## Что происходит дальше (кратко, для общего понимания)

1. Подключаетесь к серверу по SSH (через PuTTY на Windows, либо встроенный SSH в новом
   Windows Terminal).
2. Устанавливаете Docker, если его нет (одна команда).
3. Загружаете код на сервер (`git clone` — так же, как делали на своём компьютере).
4. Создаёте файл `.env` с настоящим секретным ключом (не тем, что для локального теста).
5. Запускаете одной командой:
   ```bash
   docker compose up -d --build
   ```
6. Приложение поднимается на порту 80 — открываете `http://<IP-адрес-сервера>` в браузере
   с любого компьютера.
7. Заходите под демо-аккаунтом владельца (см. `server/src/seed/seed.ts`), открываете
   в шапке раздел **«Сотрудники»** и там создаёте настоящие персональные аккаунты для
   менеджера, цеха и себя — каждому свой email и пароль. Демо-аккаунты после этого можно
   деактивировать прямо там же (кнопка «Деактивировать» в списке сотрудников).

## Про HTTPS (защищённое соединение)

Без домена (только по IP-адресу) сайт будет работать по обычному `http://`, без замка в
браузере — пароли будут передаваться по сети открыто внутри интернет-провайдера. Для 2-3
человек на первое время это приемлемо для проверки, но для постоянной работы **рекомендую**
дополнительно подключить бесплатный HTTPS-сертификат (Let's Encrypt) — для этого нужен
собственный домен (от ~150-200 ₽/год). Когда дойдём до этого шага — настрою отдельно, это
несложно добавляется поверх готового контейнера.

## Резервное копирование в продакшене

База данных лежит в Docker-томе `lhc_data` (внутри сервера, не теряется при перезапуске
контейнера). Отдельно нужно настроить периодическую выгрузку этого тома в резервную копию —
подскажу конкретные команды, когда сервер будет запущен.
